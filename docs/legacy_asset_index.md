# Legacy Asset Index

This is a navigation index for retained LabVIEW migration material and vendor
support files.  It makes the evidence searchable without replacing, renaming,
or converting the original exports.  It is not a runtime inventory, a claim of
LabVIEW equivalence, or a hardware-validation record.

For live workflow and unresolved-hardware status, use
`docs/known_open_items.md`.  For the historical migration assessment, use
`docs/labview_migration_completeness_audit.md`.

## LabVIEW migration evidence — ACTIVE / REFERENCED

| Asset | Contents | Current consumer / purpose |
| --- | --- | --- |
| `main_html/main.html` | Tracked LabVIEW HTML export | Input to `tools/parse_labview_export.py`; the export describes 305 documented VI sections and 562 referenced items. |
| `main_html/*.png` | 2,136 exported front-panel/block-diagram images | Referenced by `main.html` and recorded in `labview_manifest.json`; preserve as the visual source evidence. |
| `labview_manifest.json` | Machine-readable export index | Generated by `tools/parse_labview_export.py`; consumed by `tools/generate_port_registry.py`. |
| `port_status.json` | Machine-readable VI-to-Python registry | Generated by `tools/generate_port_registry.py`; aids migration review but is not live implementation or hardware-validation proof. |
| `src/thermo_acoustic/labview_ports.py` | Python-side registry data | Input to `tools/generate_port_registry.py`. |
| `docs/PORTING_TBD.md` | Generated historical porting checklist | Generated from the manifest and registry; historical snapshot only. |

The offline regeneration chain is:

```text
main_html/main.html + main_html/*.png
  -> tools/parse_labview_export.py -> labview_manifest.json
  -> tools/generate_port_registry.py -> port_status.json + docs/PORTING_TBD.md
```

Run either generator only when intentionally refreshing a derived registry;
the source HTML and images remain the evidence of record.

## Clearly disposable generated material

The only routinely disposable layer is interpreter/test/editor cache material:
`.pytest_cache/`, pytest basetemp folders, `__pycache__/`, and equivalent
ignored temporary output.  These are not source evidence and may be removed
when they are confirmed to be generated.  No change to `.gitignore` is needed
for that existing policy.

## Qmix boundary note

The migration index does not alter pump operation.  `QmixPumpBackend` remains
fail-closed during normal initialization: no automatic reconnect, no automatic
fault clear, and no motion command during connection.  The explicit
operator-gated fault-clear path is diagnostic recovery only; it does not show
that the CAN/interface fault is resolved.
